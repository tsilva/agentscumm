Feedback-based pruning. Keep a short ranked list and record the result of each attempted interaction in the current state. Lower candidates that produce a repeated response or no relevant state change. Reopen them only when observable feedback changes their prerequisites or shows that the prior input was ignored. Promote new candidates revealed by a state change. If no candidate has strong evidence, prefer an untried visible interaction that can clarify the next step with few inputs. Re-rank from the latest evidence rather than revisiting an exhausted branch.
